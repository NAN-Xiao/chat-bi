# S2 内置排序图标设计

## 目标

将聊天和看板表格的排序图标替换为 AntV S2 内置图标，同时保留现有列筛选漏斗、筛选弹窗及其交互。

## 范围

- 修改 `frontend/src/views/chat/component/charts/Table.ts`。
- 新增或调整针对排序图标映射的回归测试。
- 不改变排序顺序、筛选语义、筛选弹窗、表格数据请求或图表配置持久化。

## 方案

保持 `showDefaultHeaderActionIcon: false`，以便同一列头可以继续同时渲染自定义筛选图标和排序图标。

排序图标改为 S2 已注册的内置图标名称：

| 排序状态 | S2 内置图标 |
| --- | --- |
| 未排序 | `SortDown` |
| 升序 | `GroupAsc` |
| 降序 | `GroupDesc` |

筛选图标仍使用现有 `TableFilter` 和 `TableFilterActive` 自定义 SVG。点击排序仍按“未排序、降序、升序”的顺序循环，并继续调用既有排序函数。

## 验收与验证

- 表头未排序时显示 S2 的 `SortDown`；升序和降序时分别显示 `GroupAsc`、`GroupDesc`。
- 列筛选图标、筛选弹窗、全选、全不选、清除筛选保持可用。
- 排序行为仍为未排序、降序、升序循环。
- 新增回归测试先失败、实现后通过；运行关联前端测试与类型/构建检查。
