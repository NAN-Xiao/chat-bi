# 侧栏子菜单箭头位置修复设计

## 背景

工作空间管理页面左侧纵向菜单中，“系统设置”的展开/收起箭头没有贴近菜单项右侧。当前业务样式虽设置了 `right: 8px`，但实际计算样式中标题为静态定位、箭头为相对定位，同时箭头继承了通用图标的右外边距。`right` 和 `top` 因此没有相对标题边缘定位，产生水平和垂直偏移。

## 目标

- 纵向侧栏子菜单箭头固定显示在菜单项最右侧。
- 箭头距菜单项右边缘保持 `8px`，并继续垂直居中。
- 展开和收起状态的旋转动画保持不变。
- 横向顶栏菜单样式不受影响。

## 方案

在 `frontend/src/components/layout/Menu.vue` 的纵向菜单样式中，将子菜单标题显式设为相对定位，并将 `.ed-sub-menu__icon-arrow` 显式设为绝对定位和固定 `12px` 宽度。箭头清除通用图标的右外边距，使用 `right: 8px` 和与 `16px` 图标高度匹配的 `margin-top: -8px` 实现精确停靠与垂直居中。该规则仅位于 `.ed-menu-vertical` 作用域内，不修改组件结构、旋转逻辑或横向菜单样式。

## 验证

1. 增加样式回归测试，确认纵向标题建立定位上下文，箭头具有绝对定位、固定宽度、右侧定位和独立外边距。
2. 先运行测试并确认它因缺少纵向定位规则而失败，再实施样式修改并确认测试通过。
3. 运行前端构建或类型检查，确认没有引入编译问题。
4. 在页面上检查“系统设置”展开和收起两种状态，确认箭头右距为 `8px`、垂直中心误差为 `0px`，且旋转正确。

## 非目标

- 不调整菜单项文字、图标、行高或侧栏宽度。
- 不替换组件库提供的箭头节点。
- 不修改横向顶栏的下拉箭头。
