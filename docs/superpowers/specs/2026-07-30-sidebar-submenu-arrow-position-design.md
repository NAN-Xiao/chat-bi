# 侧栏子菜单箭头位置修复设计

## 背景

工作空间管理页面左侧纵向菜单中，“系统设置”的展开/收起箭头没有贴近菜单项右侧。当前业务样式已设置 `right: 8px`，但组件库为箭头元素提供了继承宽度，导致箭头容器过宽，箭头图形在宽容器内居中后产生视觉偏移。

## 目标

- 纵向侧栏子菜单箭头固定显示在菜单项最右侧。
- 箭头距菜单项右边缘保持 `8px`，并继续垂直居中。
- 展开和收起状态的旋转动画保持不变。
- 横向顶栏菜单样式不受影响。

## 方案

在 `frontend/src/components/layout/Menu.vue` 的纵向菜单样式中，为 `.ed-sub-menu__icon-arrow` 设置固定 `12px` 宽度，并保留现有的 `right: 8px`、垂直居中和旋转规则。该规则仅位于 `.ed-menu-vertical` 作用域内，不修改组件结构或横向菜单样式。

## 验证

1. 增加样式回归测试，确认纵向箭头规则同时包含固定宽度和右侧定位。
2. 先运行测试并确认它因缺少固定宽度而失败，再实施样式修改并确认测试通过。
3. 运行前端构建或类型检查，确认没有引入编译问题。
4. 在页面上检查“系统设置”展开和收起两种状态，确认箭头位置、垂直对齐和旋转均正确。

## 非目标

- 不调整菜单项文字、图标、行高或侧栏宽度。
- 不替换组件库提供的箭头节点。
- 不修改横向顶栏的下拉箭头。
