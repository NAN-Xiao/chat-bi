# 看板图表类型快捷切换设计

## 目标

在普通看板图表卡片和“从问答记录添加图表”抽屉中提供与 Smart Q&A 图表回答一致的图表类型快捷切换入口。用户切换后立即看到新的图表；有看板编辑权限时持久化配置，只读用户仅在当前页面临时切换。

## 范围

- 普通看板预览页中的单个 `SQView` 图表卡片。
- 看板编辑页“从问答记录添加图表”抽屉中的候选图表。
- 复用现有 `ChartPopover.vue` 的图标按钮、弹出菜单和选中状态。
- 保留右侧 SQL 图表配置抽屉现有的“图表类型”表单下拉框，不用快捷菜单替换它。
- 不修改数据库表、后端数据模型或迁移脚本。图表当前类型继续存入已有看板 JSON 的 `chart.type`。

## 交互

普通看板图表卡片把类型入口放入现有右上角操作栏，与解读、标签、刷新、全屏和更多操作并列。入口由当前图表图标和下箭头组成，菜单标题为“图表类型”，当前类型显示选中标记。

兼容的笛卡尔图表提供以下互换类型：

- 柱状图 `column`
- 条形图 `bar`
- 折线图 `line`
- 堆叠面积图 `area`

表格 `table` 使用相邻的独立按钮切换，与 Smart Q&A 现有交互一致。指标卡 `metric` 以及没有至少两个安全兼容类型的图表不显示无意义的类型弹出菜单。类型范围必须由当前图表配置确定，不根据字段名、数据源名称或业务领域猜测。

点击类型后立即关闭菜单并重绘当前卡片。切换不重新执行 SQL，不修改坐标轴、透视、摘要、日期筛选、数据源、SQL 或结果数据。所选类型无法使用现有明确配置渲染时展示错误，不自动替换坐标轴或字段。

## 组件与数据流

`SQComponentWrapper.vue` 负责普通看板操作栏、权限判断和持久化：

1. 根据当前 `viewInfo.chart.sourceType` 和 `viewInfo.chart.type` 构造兼容类型菜单。
2. 用户选择后调用 `sq-view/index.vue` 暴露的类型切换方法完成即时重绘。
3. `sq-view/index.vue` 更新 `chart.type`，但保留首次生成的 `chart.sourceType`，并发出类型已变更事件。
4. `dashboardInfo.canEdit === true` 时，外层使用最新的 `componentData`、`canvasStyleData` 和 `canvasViewInfo` 调用现有 `dashboardApi.update_canvas`。
5. 没有编辑权限时只保留当前页面内存中的 `chart.type`，不调用任何保存接口。刷新或重新进入看板后恢复服务端保存值。

“从问答记录添加图表”抽屉继续由 `sq-view/index.vue` 的 `multiplexing` 模式复用同一套兼容类型规则。确认添加时，当前 `chart.type` 随现有看板配置保存；取消抽屉则丢弃本次变化。

后端 `update_canvas` 已调用看板编辑权限校验，前端的 `canEdit` 仅控制产品交互，不能作为唯一安全边界。

## 保存与并发

- 切换采用乐观更新，先完成本地重绘，再保存。
- 同一图表保存期间不重复提交；连续选择以最后一次有效选择为准，保存请求按顺序执行。
- 保存请求在发送前读取最新看板配置，避免用打开菜单时的旧快照覆盖其他当前页面变化。
- 保存成功后不弹出打断操作的成功消息。
- 保存失败时恢复该次切换前的图表类型、重新渲染，并显示明确的保存失败消息。
- 只读用户的临时切换不显示“未保存”提示，因为这是预期行为。

## 权限和特殊表面

- 普通可编辑看板：显示入口，切换并持久化。
- 普通只读看板：显示入口，仅本地切换。
- 只读模板或平台模板预览：显示入口时仅本地切换，不调用普通看板保存接口。
- 非 `SQView` 组件、指标卡和失败状态图表不显示不可用入口。
- 全屏对话框读取当前内存中的 `chart.type`，打开后应与卡片当前类型一致。

## 测试

- 组件契约测试：普通看板操作栏包含 `ChartPopover` 和表格切换入口。
- 兼容类型测试：笛卡尔图表只提供 `column`、`bar`、`line`、`area`；不对指标卡显示空菜单。
- 渲染测试：选择类型后更新 `chart.type`、保留 `sourceType` 并触发重新渲染。
- 权限测试：可编辑看板调用一次保存，只读看板和模板预览不调用保存。
- 持久化测试：保存请求包含最新完整看板 JSON，刷新后保留已保存类型。
- 异常测试：保存失败恢复原类型并提示；快速连续切换不会让较早响应覆盖最终类型。
- 抽屉回归测试：候选图表切换后确认添加保留类型，取消不写入看板。
- 运行前端类型检查、相关单元测试和生产构建。
