# 修仙核心看板实时指标卡设计

## 目标

在修仙空间“核心看板”顶部新增四张实时指标卡：活跃用户、新增用户、充值人数、充值总额。

## 业务口径

- 数据源固定为 `6`，产品固定为 `prod = 110000047`。
- 当天数据只读取 `event_realtime`，并显式限制 `dt = CAST(DATE_FORMAT(CURDATE(), '%Y%m%d') AS SIGNED)`。
- 活跃用户：`UserActive` 的去重 `uid`。
- 新增用户：`UserRegister` 的去重 `uid`。
- 充值人数：`ServerPayLog` 的去重 `uid`。
- 充值总额：汇总 `ServerPayLog.personal.money`，空值按 `0` 处理，并除以 `10000` 以“万元”展示。

## 看板布局

- 四张卡位于第 1 行，横向位置依次为 `x = 1/19/37/55`。
- 每张卡使用 `sizeX = 18`、`sizeY = 8`。
- 原有组件整体向下移动 8 行，保持原相对位置不变。
- 新增组件使用固定 ID，脚本重复执行时只更新卡片内容，不再次移动原组件。

## 安全与回滚

- 修改前备份目标看板完整 `component_data`、`canvas_view_info`、版本和更新时间。
- 更新使用原值和 `update_time` 的 CAS 条件，避免覆盖并发编辑。
- 更新后重新读取并校验四个组件、SQL、布局、数据快照和原组件位移。
