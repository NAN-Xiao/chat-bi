# 分组柱状图设计

## 目标

为平台新增独立的竖向分组柱状图类型 `grouped_column`。该类型需要在 Smart Q&A、分析助手、聊天图表切换、看板图表切换、看板 SQL 编辑器、添加到看板、复制、全屏和保存回显中保持一致，并且不得改变现有 `column` 和 `bar` 图表的行为。

## 范围

本次仅新增竖向分组柱状图，不新增横向分组条形图，也不修改页面、看板网格、卡片标题、操作栏或全屏布局。

支持以下数据形态：

- 一个指标字段和一个 `series` 分类字段。
- 多个指标字段且没有 `series`。
- 多个指标字段和一个 `series` 分类字段，系列名称沿用现有“分类 / 指标”组合格式。

不在本次范围内的内容：

- 不给 `column` 增加隐式布局配置。
- 不根据数据自动把 `column` 改成 `grouped_column`。
- 不改变现有 `column` 的 `stackY` 行为。
- 不新增数据库字段或迁移。
- 不通过扩大卡片尺寸解决系列密度问题。

## 类型协议

新增稳定协议值 `grouped_column`，并加入前端 `ChartTypes`、图表实例注册表、后端允许类型及图表生成提示。现有轴协议保持不变：

```json
{
  "type": "grouped_column",
  "axis": {
    "x": { "value": "date" },
    "y": [{ "value": "amount" }],
    "series": { "value": "channel" }
  }
}
```

`grouped_column` 必须拥有有效的横轴 `x` 和至少一个指标轴 `y`。字段缺失、字段不在 SQL 结果中或配置无效时，不得用第一列、其他轴或相似字段静默替代。

## 前端架构

现有 `Column` 渲染器继续负责柱状图的通用行为，包括：

- G2 `interval` 图形。
- 坐标轴、数值格式、主题和响应式间距。
- 数据标签、提示框和图例。
- 多指标及“多指标 + series”的数据归一化。

柱状图的系列布局策略从固定 `stackY` 调整为可复用的显式策略：

- `column` 使用 `stackY`。
- `grouped_column` 使用 `dodgeX`。

新增 `GroupedColumn` 图表类并注册到现有图表工厂。它复用 `Column` 的配置构建流程，只选择不同的系列布局策略，不复制整份柱状图渲染代码。

没有 `series` 且只有一个指标时，`grouped_column` 正常渲染单列柱状图。存在多个指标或分类系列时，数据通过现有归一化逻辑形成明确的系列字段，然后使用 `dodgeX` 在同一横轴分类内并排展示。

所有柱子从同一零基线开始。系列颜色、图例顺序和提示框顺序保持输入数据及现有归一化结果的稳定顺序，不合并、不重排、不丢弃系列。

## 产品入口

以下入口增加“分组柱状图”选项并使用同一个 `grouped_column` 协议值：

- Smart Q&A 图表生成与聊天图表类型切换。
- 分析助手图表生成与显示。
- 看板图表类型切换。
- 看板 SQL 编辑器图表类型配置。
- 添加到看板、看板复制、看板预览和全屏。

图表配置保存、复制和恢复必须保留通用配置，包括 `type`、`xAxis`、`yAxis`、`series`、`columns`、数据源、SQL、结果数据、洞察配置和透视配置。不得为新类型增加只适用于单一入口的配置副本。

四种界面语言名称为：

- 简体中文：分组柱状图
- 繁体中文：分組柱狀圖
- 英文：Grouped Column
- 韩文：그룹 세로 막대 차트

## 自动生成规则

Smart Q&A 和分析助手只在以下通用分析意图下选择 `grouped_column`：

- 用户明确要求分组、并排或同组比较。
- 查询结果包含横轴分类、指标和可比较系列，并且目标是比较同一横轴分类内的系列数值。

时间趋势仍优先使用 `line` 或 `area`；结构、占比和流向仍按现有规则选择对应类型。不能仅因为结果包含多个字段就自动选择分组柱状图。规则必须保持领域无关，不使用业务表名、字段名、指标名或演示数据特例。

## 布局与密度

新类型只改变图表画布内部的柱形排列，不改变页面或卡片外部布局。它继续使用现有响应式策略：

- 在现有绘图区内缩窄柱宽。
- 在空间不足时隐藏相互重叠的数据标签。
- 保持现有坐标轴标签和图例响应式行为。
- 全屏使用同一渲染器和同一配置。

系列较多时不得自动删除系列、合并为“其他”或切换成其他图表类型。

## 错误处理

- 类型无法识别时沿用现有明确的无效类型处理，不把它映射为 `column`。
- 缺少 `x` 或 `y` 时不渲染错误含义的图表，也不选择替代字段。
- 图表类型保存失败时沿用看板现有保存失败回滚机制，恢复上一次已持久化类型。
- 添加到看板和复制流程发现配置缺失时保持现有显式失败行为，不创建含错误字段映射的图表。

## 测试与验收

自动化测试覆盖：

- 一个指标加 `series` 使用 `dodgeX` 并排展示。
- 多个指标转换为稳定系列后使用 `dodgeX`。
- 多指标加 `series` 使用“分类 / 指标”组合系列并排展示。
- 单指标无 `series` 仍可渲染。
- 现有 `column` 在存在系列时继续使用 `stackY`。
- 新类型加入前端类型联合、图表工厂、所有类型选择入口和四语种文案。
- Smart Q&A 与分析助手允许生成并保留 `grouped_column`。
- 添加到看板、复制、保存、刷新和全屏不丢失类型与轴配置。
- 无效字段不会被静默替换。

验证命令至少包括图表相关定向测试、前端 TypeScript 检查和生产构建。浏览器验收覆盖桌面和窄屏视口，确认柱子并排、普通柱状图仍堆叠、图例和标签不遮挡、类型切换可保存回显，并确认页面和看板卡片布局未发生变化。
