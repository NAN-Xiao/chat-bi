# ROI 日期表达式卡片底部遮挡修复设计

## 问题

启用日期表达式的 ROI 卡片在标题栏下新增了约 36px 高的日期工具栏，但图表内容区仍按只有标题栏时的固定高度计算。内容总高度因此超过卡片，折线图 X 轴标签和表格底部被卡片的 `overflow: hidden` 裁切。

## 范围

- 只调整启用 `date-expression-toolbar` 的 ROI 卡片。
- 不修改普通看板原日期筛选器的布局和行为。
- 不修改卡片持久化尺寸、看板数据或 SQL。
- 同时覆盖普通密度、紧凑密度，以及日期表达式与透视工具栏并存的布局。

## 方案

在 `sq-view/index.vue` 中为包含 `date-expression-toolbar` 的卡片增加专用内容区高度规则，在现有标题栏或标题栏加透视工具栏的扣减值上，再扣除日期表达式工具栏占用的高度。继续使用该组件已有的 `:has(...)` 选择器模式，避免修改组件结构或影响未启用日期表达式的卡片。

## 验证

1. 先增加布局契约测试，验证日期表达式工具栏在普通、紧凑和透视组合下都有独立高度规则，并确认测试在修复前失败。
2. 实现最小 CSS 修复后运行日期筛选相关测试。
3. 执行前端构建。
4. 在 ROI 看板验证折线图 X 轴标签和表格底部完整显示，且相邻卡片不再覆盖内容。
