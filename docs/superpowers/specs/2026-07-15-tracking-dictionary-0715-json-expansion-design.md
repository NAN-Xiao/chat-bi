`D:\AIWork3\djinchao\chat-bi\docs\xiuxian\tracking_dictionary_0715.xlsx`

## 数据源与采样边界

- 数据库：只读访问 `xtxdj`，正常查询面为 `event`、`user` 视图。
- 锚点：以 `user` 与 `event` 可用的最大业务日期为准，取最近 28 个业务日。
- 候选属性：优先处理字典中类型为 `对象组` 的属性；同时识别真实样本中值为对象、数组，或字符串内容可再次解析为对象、数组的事件属性。
- 查询范围：按候选事件过滤，只读取 `event`、`personal` 和必要的分区字段；每个事件设置样本上限，防止高频事件挤占低频事件样本。
- 安全：不执行写 SQL，不把数据库密码、UID、设备标识或完整原始事件写入文件。

## JSON 展开规则

1. 对象字段使用点号路径，例如 `ed_change.WORLD_ZHU_GUO`。
2. 对象数组使用 `[]` 标记元素层级，例如 `ed_teamInfo[].heroid`。
3. 标量数组保留为数组元素路径，例如 `ed_productIds[]`，不按数组位置生成字段。
4. 字符串仅在其完整内容是合法 JSON 对象或数组时继续解析；普通文本保持原类型。
5. 叶子类型从真实样本合并推断为 `数值`、`文本`、`布尔` 或空值；同一路径出现整数和小数时统一为 `数值`。
6. 只写入真实样本中出现的叶子路径，不根据说明栏里的示例 JSON 臆造字段。
7. 近 28 个业务日未命中可展开样本时，保留原父属性，并在属性说明中标注“近 28 个业务日未采样到 JSON 子字段”。

## 工作簿更新规则

- 只修改新文件中的“事件参数对照”Sheet；其他 Sheet 的名称、顺序、值、合并区域和关键样式保持不变。
- 已命中的父对象行替换为叶子路径行；事件块第一行保留事件信息，后续行沿用现有分组方式。
- 子字段说明以父属性说明为基础，补充路径角色和样本类型，不输出敏感样例值。
- 对旧版无父前缀的展开行，仅在同一事件中满足以下条件时移除：属性名命中本次采样的直接子键，且说明明确包含旧版子字段标记。该规则用于受控修复 `ResourceChange`，避免删除同名顶层业务属性。
- 使用用户已授权的 Python `openpyxl` 兜底流程处理工作簿；保存到同目录临时文件并验证通过后，再原子替换为最终新文件。

## 校验标准

- 原始 `tracking_dictionary_0715.xlsx` 的文件哈希在处理前后保持一致。
- 输出文件可重新打开，Sheet 名称和顺序与原文件一致。
- 除“事件参数对照”外，其他 Sheet 的值、合并区域和关键样式指纹一致。
- 已采样对象不存在未展开的父行，所有新增叶子路径都能回溯到真实样本。
- 未采样对象保留父行并带明确说明。
- `ResourceChange` 使用带父前缀的 `ed_change.*` 路径，不再保留旧版无前缀的对象子字段行。
- 扫描常见公式错误，并对“事件参数对照”代表性区域完成视觉检查。
- 采样摘要只记录日期范围、命中数、字段路径和类型，不包含凭据或用户明细。
