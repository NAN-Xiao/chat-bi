# Smart Q&A 思考过程自动展开与收起设计

## 目标

Smart Q&A 生成答案期间默认展示思考过程，答案完成后自动收起；用户完成后仍可手动展开查看。

## 交互规则

1. 新任务进入生成态时，思考过程默认展开。
2. 用户在生成期间手动收起后，后续流式内容更新不得再次自动展开。
3. `message.isTyping` 从 `true` 切换为 `false` 时，思考过程自动收起。
4. 历史已完成消息首次挂载时保持收起。
5. 完成后用户可以继续通过现有按钮手动展开或收起。

## 实现边界

在通用的 `BaseAnswer.vue` 内管理展示状态，监听 `message.isTyping` 的生命周期变化。该组件已被图表、分析和预测答案复用，因此不在父页面重复实现状态同步，也不改变后端持久化、流式协议或思考内容字段。

现有 `chat.expand_thinking_block` 配置不再决定生成态是否初始展开；本次产品行为要求生成时固定默认展开。配置字段和接口暂不删除，避免扩大变更范围。

## 状态转换

- 初始挂载且正在生成：展开。
- 初始挂载且已经完成：收起。
- 非生成态进入生成态：展开一次。
- 生成态内部内容更新：保持用户当前选择。
- 生成态进入完成态：收起。

## 测试

提取一个无 UI 依赖的状态转换函数，通过单元测试覆盖：初始生成态展开、初始完成态收起、开始生成时展开、生成期间保持用户选择、完成时收起。组件只负责把 `isTyping` 变化和用户点击接入该函数。
