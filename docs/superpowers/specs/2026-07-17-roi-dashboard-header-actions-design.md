# ROI 看板顶部操作区精简设计

## 背景

ROI 看板顶部右侧当前包含“数据源设置”“全局刷新”和“添加图表”三个入口。截图中前两个图标按钮占用视觉空间，并与图表卡片内部的日期范围和单图刷新能力形成重复入口。

## 目标

- 移除 ROI 看板顶部的“数据源设置”按钮。
- 移除 ROI 看板顶部的“全局刷新”按钮。
- 顶部右侧只保留“添加图表”按钮，使页面层级更清晰。

## 保留能力

- 保留图表卡片内部的日期范围选择器。
- 保留图表卡片内部的单图刷新、拖动排序、宽度调整、编辑和删除操作。
- 保留数据源配置弹窗、首次创建看板时的数据源配置流程和配置保存后的数据刷新。
- 保留路由切换、排序失败等内部场景使用的图表重新加载能力。

## 实现范围

主要修改 `frontend/src/views/dashboard/roi/RoiDashboardPanel.vue`：

1. 删除顶部操作区的两个 `el-tooltip` 和对应按钮。
2. 删除不再使用的 `Setting`、`RefreshRight` 图标导入。
3. 删除只服务于顶部全局刷新按钮的 `refreshCurrentCharts()`。
4. 保留 `reloadCharts()`、`reloadChartsAfterConfigSave()` 和数据源弹窗相关逻辑。
5. 更新 ROI 面板测试，确认顶部入口消失且卡片内部操作仍存在。

## 验收标准

- ROI 看板顶部只显示“添加图表”按钮。
- 页面中不再出现顶部“设置数据源”和“刷新图表”图标按钮。
- 图表卡片内部日期选择和单图刷新功能正常。
- 新建看板、编辑图表、保存数据源配置和异常恢复流程不受影响。
- 前端 ROI 相关测试、类型检查和生产构建通过。

## 非目标

- 不删除数据源配置 API、Store 状态或弹窗组件。
- 不删除内部图表重载方法。
- 不改变图表卡片的操作按钮和权限逻辑。
- 不调整看板标题、数据源名称和“添加图表”按钮的业务行为。
