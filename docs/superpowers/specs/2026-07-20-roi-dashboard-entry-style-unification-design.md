# ROI 看板固定入口样式统一设计

## 背景

ROI 看板固定入口已经移动到“推荐看板”之下，但该节点仍使用虚拟分组的彩色图标和分组视觉。与同级的“核心看板”“留存分析”等普通推荐看板相比，图标尺寸、颜色和文字起始位置不一致，容易让用户误以为 ROI 仍是独立顶层模块。

本次只统一固定入口的视觉表现，不改变 ROI 子看板、路由、权限、菜单、排序和数据模型。

## 目标

- ROI 固定入口与普通推荐看板使用相同的灰色看板图标。
- ROI 固定入口与普通推荐看板的文字起始位置、行高、字号、悬停背景和选中背景一致。
- 有下属 ROI 看板时继续显示展开箭头，并可展开、收起下属节点。
- 固定入口的三点菜单继续仅在悬停时显示，保留新建下属看板和排序能力。
- ROI 子看板继续使用现有普通看板叶子样式。

## 方案对比

### 方案一：按节点角色覆盖视觉，推荐

保留 ROI 固定入口的虚拟分组身份和 `node_type = 'folder'`，仅为其增加明确的视觉角色标识。模板根据该角色使用普通推荐看板的灰色网格图标，并让该节点在推荐看板层级中采用与叶子节点相同的对齐规则。

优点是业务结构完全不变，展开、菜单和排序逻辑继续复用现有实现；缺点是模板需要一个小范围的 ROI 入口视觉分支。

### 方案二：只替换彩色图标

仅把彩色分组图标替换成灰色网格图标，不调整缩进和尺寸。

改动最少，但文字位置和展开图标占位仍可能与普通推荐看板不一致，不能解决截图中的完整视觉差异。

### 方案三：把固定入口伪装成叶子节点

将 ROI 固定入口改为 `node_type = 'leaf'`，从而自动复用普通看板模板。

该方案会影响 Element Tree 的展开判断、拖放、菜单和路由分发，容易破坏下属 ROI 看板能力，因此不采用。

## 视觉规则

ROI 固定入口的最终表现遵循普通推荐看板叶子规则：

- 图标使用现有 `icon_dashboard_grid_add`，尺寸、颜色和选中缩放与普通推荐看板一致。
- 默认图标颜色使用资源树的次级文字色；选中时使用现有主色。
- 节点高度继续为 `32px`，字号继续为 `13px`，不新增独立颜色或圆角。
- 文字与图标之间的间距沿用普通推荐看板节点。
- 悬停和选中状态继续使用资源树统一的 `--hover-color` 与 `--active-color`。
- 三点菜单保持右侧定位和悬停显示，不因视觉统一而永久显示。
- 展开箭头只表达是否存在下属 ROI 看板，不改变固定入口的业务身份。

## 组件设计

主要修改 `frontend/src/views/dashboard/common/ResourceTree.vue`：

1. 在节点 class 中为 `isRoiGroupNode(data)` 增加明确的固定入口样式类。
2. 图标渲染时让 ROI 固定入口走普通推荐看板的 `icon_dashboard_grid_add` 和 `icon-primary` 样式，而其它虚拟根分组继续使用彩色分组图标。
3. 使用局部样式修正 ROI 固定入口在推荐看板层级中的图标和文字对齐，不修改全局 Element Tree 缩进。
4. 保留 `node_type = 'folder'`、`virtual = true` 和 `dashboard_scope = 'roi'`，避免视觉改动进入业务判断。

不修改 `HandleMore.vue`；现有菜单显示时机和菜单项已经符合要求。

## 数据与交互边界

- 不修改 `CoreRoiDashboard`、普通看板或资源树数据库记录。
- 不修改 `buildCombinedTree()` 的层级结构。
- 不修改 ROI 固定入口点击、空路由、初始选择和权限逻辑。
- 不修改 `newRoiDashboard`、`toggleTreeEditing` 白名单。
- 不修改 ROI 子看板的重命名、删除、排序和图表编辑能力。
- 不修改普通推荐看板及“我的看板”的图标和样式。

## 测试设计

更新 `frontend/src/views/dashboard/common/ResourceTree.roi.test.mjs`，验证：

- ROI 固定入口具有专用视觉 class。
- ROI 固定入口使用普通看板网格图标和 `icon-primary` 样式。
- 其它虚拟分组仍使用彩色分组图标。
- ROI 固定入口仍是虚拟 folder，未被改成 leaf。
- ROI 固定入口菜单仍保留 `newRoiDashboard`、`toggleTreeEditing`，且不包含删除、重命名或复制命令。

运行现有资源树与 ROI 导航测试，并执行生产构建。最后在本地页面检查默认、悬停、选中、展开和空子树五种状态。

## 验收标准

- ROI 固定入口的图标、文字位置、行高、字号、悬停和选中效果与普通推荐看板一致。
- ROI 固定入口不再显示彩色分组图标。
- 有下属看板时可以正常展开；无下属看板时布局不跳动。
- 三点菜单继续在悬停时显示，菜单能力不变。
- 普通推荐看板、我的看板和其它虚拟根分组视觉不变。
- 资源树和 ROI 相关测试及生产构建通过。

## 非目标

- 不重新设计整个看板侧栏。
- 不移除 ROI 固定入口的展开能力或菜单。
- 不调整推荐看板排序、ROI 排序或拖放规则。
- 不新增后端接口、数据库迁移或兼容逻辑。
