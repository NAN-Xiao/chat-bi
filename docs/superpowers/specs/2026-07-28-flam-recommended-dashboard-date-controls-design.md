# Flam 推荐看板日期控件设计

## 目标

为 Flam 推荐看板中用户指定的非实时、非当日业务抽屉补齐可执行的日期表达式控件；切换日期必须改变查询窗口，而非仅改变页面标签。

## 范围

迁移覆盖留存、核心、新增、活跃、付费、主城、出征、渠道、活动、ROI 与投放看板中的指定抽屉。保留以下排除项：ChatMon 看板、实时看板、标题为“当日”的指标，以及“日充值用户数”。已经启用日期表达式的“购买月卡用户的30日留存”仅验证，不重复迁移。

## 方案

使用一个幂等迁移脚本维护显式目标清单。每个目标声明业务日期字段和 SQL 中对应的旧日期窗口；脚本将其替换为看板起止参数，并写入 `sourceConfig.sql.builder` 与 `pivot` 的日期表达式配置。对留存/LTV 类指标，日期范围用于 cohort/新增/购买日期，观察窗口仍保持指标要求的成熟期。

## 安全与验证

脚本默认预演，应用模式对每个看板先生成备份，以行锁和原始画布 JSON CAS 更新。迁移后读回校验：每个目标具有日期控件、预期数量的参数、正确日期字段；所有非目标抽屉哈希不变。测试覆盖目标选择、SQL 替换拒绝条件和读回校验。
