# 修仙推荐看板抽屉日期控件设计

## 目标

为修仙空间的推荐看板抽屉启用既有日期表达式控件，默认范围为最近 30 天。用户应用新范围后，图表通过平台现有的日期筛选执行链路重新查询。

## 范围

- 只处理修仙空间、其绑定数据源和 `default` 范围内的推荐看板。
- 只处理具备普通 SQL 查询且日期筛选能力有效的抽屉图表。
- 不处理“我的看板”、其他空间、外部 MCP 图表、没有 SQL 的图表及日期筛选能力无效的图表。
- 不修改图表 SQL、标题、数据源、布局、透视配置或其他图表元数据。

## 实现方案

新增一个可重复执行的迁移脚本。脚本在只读预演模式下枚举修仙推荐看板和抽屉，识别可启用的图表；`--apply` 才写入配置。对每个目标图表写入现有日期表达式配置：

```json
{
  "version": 1,
  "mode": "preset",
  "preset": "past_30_days"
}
```

脚本同步设置 SQL 构建器的日期表达式入口和图表 `pivot.date_expression`。前端继续使用已有 `DashboardDateExpressionPicker` 与图表执行接口，不根据工作空间名称增加分支。

## 安全与回滚

- 写入前按租户、数据源、推荐树范围和抽屉身份校验目标，拒绝范围不匹配。
- 写入前保存完整原始 `canvas_view_info` 到 `.codex-runtime` 下的备份文件。
- 更新以原始画布文本为 CAS 条件，避免覆盖并发修改。
- 提交后重新读取并验证日期配置和未变更字段。
- `--restore <backup>` 仅在当前画布仍匹配本次迁移结果时恢复备份。

## 验证

- 单元测试覆盖目标空间/推荐范围筛选、默认 30 天配置、SQL 与非目标字段不变、不可用图表跳过、CAS 拒绝和回滚前置条件。
- 对目标环境先运行预演，确认目标看板和抽屉清单；执行后运行只读验证。
- 前端检查确认日期控件只出现在已启用的修仙推荐看板 SQL 抽屉，点击“应用”会触发既有刷新路径。
