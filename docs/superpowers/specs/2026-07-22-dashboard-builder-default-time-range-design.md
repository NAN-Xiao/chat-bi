# 图表生成器默认时间范围设计

## 目标

新建图表或图表缺少已保存时间字段时，时间范围默认显示为：

- 时间字段：优先选择业务日期、分区日期或语义角色为 `partition_date` 的字段
- 时间粒度：按天
- 时间范围：过去 30 天

已有图表已经保存的时间字段、粒度和范围必须原样回填，不得被默认值覆盖。

## 实现范围

调整 `DashboardSqlEditor.vue` 中通用时间字段优先级：

1. 分区日期、业务日期及 `partition_date` 语义优先。
2. 事件日期、事件时间次之。
3. 普通日期和时间字段继续作为后续候选。

现有 `day` 和 `30d` 默认值保持不变。默认字段仍只在 `sqlBuilder.timeField` 为空且字段元数据加载完成后写入。

## 兼容性

- 不按数据源名称、表名或字段名硬编码业务规则。
- 不覆盖已保存的 `timeField`。
- 无业务日期或分区日期字段时，沿用现有事件日期和普通时间字段回退顺序。

## 验证

- 回归测试证明业务日期/分区日期优先于事件日期。
- 回归测试证明缺少业务日期时仍选择事件日期。
- 保留现有断言，确认字段加载后只通过统一优先级函数填充空默认值。
- 运行相关前端测试和 TypeScript 构建检查。
