# 修仙埋点对象参数展开设计

## 目标

修复 `tracking_dictionary_template_xiuxian.xlsx` 的“事件参数对照”页：后端页中类型为 `object` 的事件参数，依据数据库真实样本展开为可查询的 JSON 子字段。

## 数据范围

- 打点定义来源：`修仙项目-BI打点整理.xlsx` 的“后端”页。
- 采样来源：`xtxdj.event` 视图，固定产品 `110000047`。
- 采样窗口：以 `user` 视图最大业务日期 `20260713` 为锚点，取 `20260616` 至 `20260713`。
- 采样策略：一次按目标事件集合读取有限候选行，在本地解析 `personal` JSON；不在数据库端逐字段 JSON 过滤，也不进行无索引的全历史扫描。

## 处理规则

1. 仅处理后端页参数类型为 `object` 的记录。
2. 对近 28 天内有真实 JSON 样本的对象参数，按实际标量叶子路径展开，例如 `ed_change.WORLD_ZHU_GUO`、`ed_drawResult[].itemId`。
3. 子字段类型由真实样本推导为数值、文本或布尔；数组对象使用 `[]` 标记数组元素层级。
4. 子字段备注由父参数说明与子字段含义组成；能够从字段名或定义说明确认的含义写入备注，无法确认的 ID/枚举键明确标注其数据角色，不臆造业务语义。
5. 近 28 天未采到真实样本的对象参数保留原对象行，并在备注中明确说明未采样，不从原表样例 JSON 推导子字段。
6. 保留“事件参数对照”既有列顺序、事件分组方式、表格结构和视觉样式；不修改其他工作表的业务内容。

## 校验

- 检查已展开字段均来自采样结果，且其父事件、参数名与后端页定义一致。
- 检查未采样对象参数不产生未证实子字段。
- 扫描公式错误并渲染“事件参数对照”页，确认列宽、换行和事件分组可读。
