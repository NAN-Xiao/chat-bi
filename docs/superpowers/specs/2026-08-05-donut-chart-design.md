# 全平台独立环形图设计

## 目标

在 Smart Q&A、分析助手、看板和看板 SQL 编辑器中新增独立 `donut` 图表类型。现有 `pie` 行为保持不变，不新增数据库字段或迁移。

## 类型与数据协议

环形图配置继续使用饼图的字段协议：一个数值字段 `y` 和一个分类字段 `series`。

```json
{
  "type": "donut",
  "title": "用户区间分布",
  "axis": {
    "y": { "value": "user_count" },
    "series": { "value": "range_name" }
  }
}
```

AI 仅在用户明确要求“环形图”“圆环图”或 `donut chart` 时选择 `donut`。普通占比、构成和分布问题继续沿用现有 `pie`、`treemap` 或 `bar` 选择逻辑。

## 前端架构

抽取共享径向分区图实现，统一处理 G2 `theta` 坐标、扇区堆叠、图例、tooltip 和响应式布局：

- `Pie` 使用 `innerRadius: 0`，保持现有标签与视觉行为。
- `Donut` 使用 `innerRadius: 0.55`，中心保持空白。
- 环形图启用标签时显示“分类名称 + 数值 + 占比”，tooltip 使用同一数值和占比结果。
- 百分比最多保留两位小数并去除末尾零。

所有业务入口通过同一个 `ChartComponent` 和图表注册表渲染。看板编辑器、全屏、摘要布局和推荐尺寸将 `donut` 视为与 `pie` 相同的结构类图表，但持久化类型始终保留为 `donut`。

## 校验与错误处理

环形图不静默替换字段、聚合重复分类或降级成其他图表类型。

- 必须配置一个数值字段和一个分类字段。
- 分类不能为空且同一分类只能出现一次。
- 数值必须是有限的非负数。
- 所有数值合计必须大于零。
- 分类数量最多为 12 个。

配置或数据错误显示明确的本地化错误状态，不执行临时渲染重试，也不继续展示旧图。G2 初始化等临时错误继续使用现有重试机制。

## 后端接入

- 通用图表类型白名单加入 `donut`。
- Smart Q&A 图表模板加入 `donut` 类型、字段示例和显式请求规则。
- 分析助手类型集合和字段映射接受 `donut`。
- 不修改各数据库方言 SQL 示例，因为环形图与饼图使用相同查询结构。

## 测试与验收

- 单元测试覆盖径向图配置、占比格式和所有校验错误。
- 契约测试覆盖图表注册、类型选择器、看板保存恢复和后端白名单。
- 回归测试证明普通占比问题仍使用 `pie`，现有饼图配置不含内半径。
- 前端构建和相关后端测试必须通过。
- 使用七个区间的示例数据验证 Smart Q&A、看板、全屏、桌面和移动端；中心孔必须可见，标签不得重叠，tooltip 与标签占比一致。
