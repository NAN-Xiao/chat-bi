# 修仙核心与 ROI 看板视觉同步设计

## 目标

以 flam 空间当前默认推荐“核心看板”和“ROI看板”为视觉基准，把对应图表类型、可用字段映射、标题和布局从 flam 同步到“修仙”空间。同步方向固定为 flam 到修仙，不反向修改 flam。

修仙看板继续使用数据源 `6`、现有 SQL、日期参数、业务口径和已有数据。不得把 flam 数据源 `3`、产品 ID、表名、字段或 SQL 复制到修仙。

## 目标记录

只修改系统数据库 `core_dashboard` 中以下两条默认推荐看板：

| 空间 | 看板 | 看板 ID | 租户 ID | 数据源 |
| --- | --- | --- | ---: | ---: |
| 修仙 | 核心看板 | `afe201c9762c448aa0495f3508c01793` | `7482727237662281728` | `6` |
| 修仙 | ROI看板 | `17531de20e5d439f9ddfb2eeececced5` | `7482727237662281728` | `6` |

查询还必须联结 `core_dashboard_tree` 并校验 `scope = 'default'`。同名个人看板及 flam 空间记录不在写入范围内。

## 核心看板同步

按图表标题匹配 flam 与修仙的同语义图表，不按数组下标或组件 ID 猜测映射。

- `ARPU与ARPPU` 改为柱状图；横轴和指标继续引用修仙 SQL 实际返回的 `dt`、`ARPU`、`ARPPU`。
- `新增用户趋势` 改为柱状图；继续使用修仙的日期和新增用户字段。
- `每日渠道新增用户` 改为面积图；保留日期横轴、新增用户数指标和渠道系列。
- 其他同名图表保持当前类型，但统一检查轴、系列、标题和双列布局是否与 flam 的视觉结构一致。
- 修仙独有的 `新增用户ARPU与ARPPU` 保留；flam 独有且修仙没有既有业务口径的图表不新增。

四张指标卡保持首行四等分、每张高度 `10`。普通图表继续采用两列结构；修仙独有图表参与本空间的无重叠顺排，不为了模仿 flam 而制造空位。

## ROI 看板同步

保留修仙四个现有 ROI 视图及其 SQL，并新增一个 ROI 柱状图视图。新增视图复制修仙 `ROI总览` 的数据查询配置和日期配置，只替换视图 ID 与图表展示配置，不复制 flam SQL。

目标布局与 flam 当前 ROI 看板一致：

| 顺序 | 图表 | 类型 | 位置与尺寸 |
| --- | --- | --- | --- |
| 1 | 安装投放趋势 | 折线图 | `x=2, y=1, sizeX=34, sizeY=17` |
| 2 | 图表 | 柱状图 | `x=36, y=1, sizeX=36, sizeY=17` |
| 3 | ROI地区总览 | 面积图 | `x=2, y=18, sizeX=70, sizeY=18` |
| 4 | ROI广告地区总览 | 柱状图 | `x=2, y=37, sizeX=70, sizeY=16` |
| 5 | ROI数据总览 | 表格 | `x=2, y=53, sizeX=70, sizeY=15` |

新增顶部右侧 `图表` 的字段映射为：横轴 `日期`，指标 `首日ROI` 和 `3日ROI`，无系列字段。`ROI地区总览` 使用日期横轴、首日及 3 日 ROI 指标、地区系列；`ROI广告地区总览` 使用日期横轴、修仙 SQL 已有数值指标、广告渠道系列。原 `ROI总览` 标题同步为 `ROI数据总览` 并移动到底部。

## 写入安全

新增一个定向迁移脚本，默认只读，只有显式传入 `--apply` 才写数据库。脚本必须：

1. 校验租户、数据源、看板 ID、名称、默认推荐目录绑定和现有组件清单。
2. 在写入前保存两条看板的完整原始行、原新 JSON 哈希和可执行回滚信息。
3. 获取每个看板的 PostgreSQL advisory transaction lock。
4. 使用原 `component_data` 与 `canvas_view_info` 作为 CAS 条件更新；任一行未精确更新一次则整体回滚。
5. 事务内读回并验证，再提交。
6. 重复执行时识别已完成状态，不重复新增 ROI 图表。

## 验证

自动化测试覆盖纯函数转换、缺失或重复目标、字段不匹配、幂等性、布局重叠及 CAS 失败。数据库只读验证必须证明：

- 只有两条修仙默认推荐看板发生目标内变化；
- 修仙所有原有视图的 SQL 哈希、数据源、日期配置和业务字段未被改写；
- ROI 新视图的 SQL 与修仙原 `ROI总览` SQL 一致；
- 核心看板和 ROI 看板组件数量、图表类型、字段映射、标题及布局符合本文目标；
- 所有组件 ID 唯一且布局无重叠；
- flam 看板哈希保持不变。

最后通过本地前端分别打开修仙核心看板和 ROI 看板，检查图表正常渲染、日期筛选可用、抽屉尺寸合理且没有重叠。
