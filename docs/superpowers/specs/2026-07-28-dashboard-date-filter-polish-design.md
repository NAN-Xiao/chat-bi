# 仪表板日期筛选器视觉优化设计

## 背景

仪表板图表卡片中的日期范围选择器已具备日期展示、范围选择、面板定位和应用能力，但当前外观接近默认表单控件，与卡片标题及表格的视觉层级衔接较弱。

## 目标

- 将日期选择器呈现为紧凑的仪表板工具条控件。
- 增强日期信息、图标和展开状态的视觉层级。
- 保持现有日期选择、禁用、加载、应用和响应式行为不变。
- 不调整日期弹层逻辑、日期参数协议或后端接口。

## 视觉方案

日期触发器保持在图表标题下方、表格上方，高度保持 `30px`。宽度由固定值调整为内容自适应，并设置合理的最小宽度和最大宽度，避免短日期留白过多，同时保证长文本可以省略显示。

控件默认使用浅灰背景、低对比度边框和 `6px` 圆角。日历图标置于轻量色块中，日期文字使用主文本色，末端保留展开箭头。整体风格应融入仪表板工具区，不表现为独立的大型输入框。

交互状态如下：

- 悬停：背景变白，边框对比度轻微增强。
- 键盘聚焦：显示清晰但克制的品牌色焦点环。
- 展开：使用品牌色边框和浅品牌色背景，箭头旋转 180 度。
- 禁用或应用中：保留现有不可点击行为，降低对比度但保持文字可读。

## 结构与实现边界

继续使用 `frontend/src/views/dashboard/components/sq-view/index.vue` 中现有的 `date-filter-toolbar` 和 `date-filter-trigger`。通过现有的 `dateFilterPanelVisible` 状态增加展开态类名或属性选择器，不新增业务状态，也不拆分新组件。

本次只修改触发器相关模板标记和 Less 样式。日期格式化、面板月份对齐、日期范围校验、应用请求及错误处理均保持不变。

## 响应式与可访问性

- 宽容器下按内容自适应，避免无意义占满横向空间。
- 窄容器下宽度不超过父容器，日期文本使用单行省略。
- 保留原生 `button`、`disabled` 和 `aria-expanded` 语义。
- `focus-visible` 状态必须可辨识，不能只依赖颜色极弱的边框变化。

## 验证

- 先补充结构测试，覆盖展开态类名或属性、日期图标容器和响应式样式约束，并确认测试在实现前失败。
- 完成样式后运行日期筛选器相关前端测试和 TypeScript 构建检查。
- 在桌面和窄屏视口检查默认、悬停、展开及禁用状态，确认控件不挤压标题、菜单或表格内容。

## 非目标

- 不重做日期弹层。
- 不增加快捷日期范围或新的筛选能力。
- 不改变卡片标题、表格主题或其它仪表板组件。
