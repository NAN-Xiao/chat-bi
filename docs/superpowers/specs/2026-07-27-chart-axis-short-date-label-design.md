# 非明细图表日期轴短格式设计

## 目标

看板及智能问答复用的非明细图表，在横轴值为标准日期时，将刻度标签从 `2026-07-27` 缩写为 `07/27`，减少标签拥挤。

## 展示规则

- 只格式化图表坐标轴刻度，不修改原始查询结果、图表配置或字段值。
- `YYYY-MM-DD` 以及以该日期开头的标准日期时间值，横轴刻度显示为 `MM/DD`。
- 鼠标悬停提示继续显示原始完整日期，避免跨年数据产生歧义。
- 明细表继续显示原始完整日期。
- 非日期字符串、数字、空值和无法严格识别的值保持原样，不猜测业务字段含义。

## 实现方案

在 `frontend/src/views/chat/component/charts/utils.ts` 增加无副作用的日期轴标签格式化函数。函数只根据当前刻度值进行严格识别，不依赖 `dt`、`date`、`日期` 等字段名，保持平台领域无关。

折线图、面积图、柱状图、条形图以及混合单位组合图的分类轴配置复用该函数作为 `labelFormatter`。图表 Tooltip 仍读取原始数据，因此无需增加兼容逻辑。明细表使用独立渲染组件，不接入该函数。

本次不修改 SQL、后端接口、持久化结构、Data Skill、看板数据和 SSR 图表渲染链路。

## 数据流

1. 后端查询结果保留完整日期值，例如 `2026-07-27`。
2. `ChartComponent` 将原始数据交给具体 G2 图表类。
3. G2 生成坐标轴刻度时调用共享格式化函数，输出 `07/27`。
4. Tooltip 和导出数据继续读取原始值 `2026-07-27`。

## 异常与边界

- `null`、`undefined` 和空字符串遵循现有图表行为。
- 不接受宽松日期解析，避免把普通分类编码误识别为日期。
- 月、日必须处于合法范围；非法值保持原样。
- 时间部分存在时只截取已校验日期的月和日，不进行时区换算。
- 相同 `MM/DD` 出现在不同年份时只影响轴标签；Tooltip 仍可区分完整日期。

## 测试与验证

- 先为共享格式化函数增加失败测试，覆盖纯日期、日期时间、普通文本、数字、非法日期和空值。
- 增加图表配置契约测试，确认主要非明细图表及混合单位路径都使用共享格式化函数。
- 运行相关前端测试和生产构建。
- 如本地页面可用，在桌面看板检查横轴显示 `07/27`，悬停仍显示完整日期，明细表保持不变。

## 验收标准

- 截图所示非明细图表横轴日期显示为 `MM/DD`。
- Tooltip 与明细表仍显示完整原始日期。
- 非日期分类值不发生变化。
- 不引入数据改写、字段名猜测或兼容性回退。
