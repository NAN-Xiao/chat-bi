# 表格图表本地取消分组

分组列筛选中的“空值：不分组”表示取消该列的展示分组，并保留其余维度（包括仍被保留的日期维度）。该操作只汇总当前已加载的数据，不重新执行 SQL，也不读取业务数据库。清除筛选或选择普通分组值可恢复原分组。

共享表格组件用于智能问数、看板、看板编辑预览、全屏预览、共享图表预览及分析助手。已有 SQL 的结构解析接口 `/dashboard/local_grouping_plan` 只接收 SQL 文本和可选方言，不接收数据源连接或业务数据，不执行查询。编辑器使用产生当前预览数据的 `lastPreviewSql`，避免将正在编辑的新公式应用于旧结果。

本地汇总规则来自 SQL 中明确声明的分组、聚合和计算表达式，不按字段名猜测业务含义：

- 可相加指标及最小值、最大值按声明的方式合并。
- 比率和加权平均只有在已有数据包含可靠的原始计算字段、且运算口径明确时才重新计算。
- 舍入后的金额可以对当前已加载结果求和，但不会被当作未舍入的原始分子或分母。
- 去重聚合、缺少分母或权重、除法数值类型不明确、字段缺失、超出数值安全精度等情况显示“无法本地计算”，并在提示中说明原因。
- 原汇总行不参与明细的重复累加。联合查询中的每个聚合分支都必须具有可验证的汇总标记；无法区分明细和小计时禁用取消分组并明确提示。

维度值筛选先作用于明细，指标值筛选作用于汇总后的结果。导出和看板报告读取当前可见数据。分组变化仅是当前组件的展示状态，不改写原 SQL 或已保存的业务配置。
