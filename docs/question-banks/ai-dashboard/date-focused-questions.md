# AI 看板日期语义专项测试题

这组问题用于验证 AI 看板对相对日期、自然周期、绝对日期区间、比较窗口和时间粒度的解析。每题都可以独立提交；“最近/近/过去 N 天”建议检查是否按平台约定查询截至昨天的 N 个完整自然日。

日期范围约束：所有题目的最大日期跨度不超过两个月，且固定日期不得晚于今天（2026-08-19）；滚动范围最长为 60 天，固定区间限定在相邻两个月以内。
