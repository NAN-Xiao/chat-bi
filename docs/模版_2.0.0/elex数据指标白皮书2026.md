# Elex 游戏业务术语知识库


通用约定：未指定日期时，以数据源最大可用业务日期为锚点分析最近28天；新增队列日期与后续观察窗口分别确定。“注册前N日”包含注册当天，“第N日留存”观察注册日之后第N日。比率分母为0或缺失时返回NULL，观察窗口未成熟不能按0处理。跨维度比率先汇总分子分母后相除，不直接平均百分比。

## 1. 新增用户

别名：新用户、新注册、纯新用户、New Users

定义：首次进入游戏并产生游戏行为的新用户。白皮书明确运营报表、总览概览、留存报表及 MVP 运营数据的新增用户不包含重玩用户。

计算公式：`新增用户数 = COUNT(DISTINCT 首次产生游戏行为且满足纯新条件的UID)`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 注册时间按首次收到带UID行为日志的时间判定，不能未经确认换成账号表创建时间。
- 白皮书明确运营报表、总览概览、留存报表和MVP运营数据的新增用户不包含重玩。

### SQL 示例

暂无。

## 2. 重玩

别名：重玩用户、重玩人数

定义：统计期内新建账号、且注册设备此前已注册过账号的用户数。

计算公式：`重玩人数 = COUNT(DISTINCT 新账号且注册设备此前创建过账号的UID)`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 必须依据注册设备此前的账号历史判定；重复登录同一账号不是重玩。

### SQL 示例

暂无。

## 3. 新增超R人数

别名：新增超R用户数、七日超R人数

定义：新注册用户在注册 7 日内，含注册当天，累计充值达到或超过 1000 美元的人数。

计算公式：`新增超R人数 = COUNT(DISTINCT 注册前7日累计充值>=1000美元的新用户UID)`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 注册前7日包含注册当天，金额阈值为累计充值≥1000美元。
- 仅统计完整可观察的新增队列；不能与滚动30日大R标签混用。
- 有效支付、订单去重、退款、币种及金额单位由当前工作空间配置；美元阈值不得与其他币种直接比较。

### SQL 示例

暂无。

## 4. 大R转化率

别名：新增大R转化率、三日大R转化、七日大R转化、30日大R转化

定义：新增队列中在指定注册窗口内达到对应充值阈值的人数占比。3 日累计充值 ≥300 美元；7 日 ≥1000 美元；30 日 ≥3000 美元。分母为同一新增队列，成熟度另行校验。

计算公式：`N日大R转化率 = 注册前N日充值达到对应阈值的新增人数 / 同一成熟新增队列人数 * 100%`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 3日阈值≥300美元，7日阈值≥1000美元，30日阈值≥3000美元，均包含注册当天。
- 分子分母使用同一成熟新增队列；不能把不同窗口阈值互换。
- 使用完整可观察的队列与窗口；缺失记录、未成熟状态和真实零值分别处理。
- 有效支付、订单去重、退款、币种及金额单位由当前工作空间配置；美元阈值不得与其他币种直接比较。

### SQL 示例

暂无。

## 5. 新注册付费人数

别名：新用户付费人数、新增付费人数、首日新增付费人数

定义：新增用户中注册首日发生付费的人数；不是统计日所有首次充值人数。

计算公式：`新注册付费人数 = COUNT(DISTINCT 注册首日有付费的新用户UID)`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 限定新增队列的注册首日，不等同于统计日全部首充人数。
- 有效支付、订单去重、退款、币种及金额单位由当前工作空间配置；美元阈值不得与其他币种直接比较。

### SQL 示例

暂无。

## 6. 新增核心SLG玩家数

别名：新增核心SLG用户、三日核心玩家数

定义：新增用户在注册 3 日内，含注册当天，累计在线时长严格大于 180 分钟的人数。

计算公式：`新增核心SLG玩家数 = COUNT(DISTINCT 注册前3日累计在线时长>180分钟的新用户UID)`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 前3个统计日包含注册当天，时长阈值为严格大于180分钟。
- 该标签属于白皮书游戏场景，不能成为其他行业或游戏项目的默认核心用户规则。

### SQL 示例

暂无。

## 7. 新增高价值潜力用户数

别名：新增高价值潜力用户、三日高价值潜力人数

定义：新增用户在注册 3 日内，含注册当天，累计付费严格大于 50 美元的人数。

计算公式：`新增高价值潜力用户数 = COUNT(DISTINCT 注册前3日累计充值>50美元的新用户UID)`

关联事件：当前工作空间定义的首次带UID游戏行为与注册队列；涉及重玩时关联设备账号历史，涉及充值或在线标签时关联对应明细

### 约束条件

- 前3个统计日包含注册当天，充值阈值为严格大于50美元，不是≥50美元。
- 有效支付、订单去重、退款、币种及金额单位由当前工作空间配置；美元阈值不得与其他币种直接比较。

### SQL 示例

暂无。

## 8. 安装用户/install

别名：安装、安装设备数、Install

定义：安装设备数，数据来源为第三方平台；不是新增账号数。

计算公式：`安装用户数 = 第三方平台按其安装口径统计的设备数`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 来源为第三方平台安装设备数据，不能用注册UID数代替。
- 去重与重复安装处理遵循来源平台配置。

### SQL 示例

暂无。

## 9. 自然量占比

别名：自然用户占比、Organic Share

定义：在相同国家、地区或平台等人群范围内，自然量进入游戏的玩家占该范围全部玩家的比例。自然量的归因识别方式需配置。

计算公式：`自然量占比 = 指定人群中的自然量玩家数 / 同一范围全部玩家数 * 100%`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 分子分母使用同一国家、地区或平台等人群范围。
- 自然量归因标识必须来自当前数据源配置，不能仅按渠道名称猜测。

### SQL 示例

暂无。

## 10. 首日创角设备数

别名：安装首日创角设备数

定义：在设备安装当天创建角色的设备数。

计算公式：`首日创角设备数 = COUNT(DISTINCT 安装当天创建角色的设备标识)`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 主体为设备，观察日期为安装当天，不是账号注册后任意日期。

### SQL 示例

暂无。

## 11. 首日创角率

别名：安装首日创角率

定义：首日创角设备数 ÷ 安装设备数，分子分母使用相同安装队列。

计算公式：`首日创角率 = 首日创角设备数 / 同一安装队列设备数 * 100%`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 分子分母必须使用同一安装队列，不能把创角人数除以安装设备数。

### SQL 示例

暂无。

## 12. 花费

别名：广告花费、投放花费、买量成本、Spend

定义：广告平台用于买量的成本，来自第三方或广告平台费用数据。

计算公式：`花费 = SUM(指定广告范围内的有效买量费用)`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 费用范围、归因维度、币种和时区由广告来源配置确定。
- 游戏支付日志不能代替广告花费。

### SQL 示例

暂无。

## 13. impressions

别名：曝光量、广告曝光次数、Impressions

定义：广告素材曝光次数。

计算公式：`曝光次数 = SUM(来源平台记录的广告曝光次数)`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 统计曝光次数，不是去重曝光用户数。
- 第三方数据粒度应避免跨层级重复汇总。

### SQL 示例

暂无。

## 14. clicks

别名：广告点击次数、Clicks

定义：广告实际点击次数；不能使用去重点击用户数替换。

计算公式：`点击次数 = SUM(来源平台记录的实际广告点击次数)`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 统计实际点击次数，不能替换为点击用户数。
- 是否以目标页到达次数定义点击，由广告来源口径决定。

### SQL 示例

暂无。

## 15. CPC

别名：单次点击成本、Cost Per Click

定义：每次广告点击的成本；数学表达为花费 ÷ 点击次数。

计算公式：`CPC = 花费 / 点击次数`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 公式是对单位点击成本含义的数学表达；白皮书未另列明确公式。
- 使用前核对第三方花费与点击的范围及平台直接返回口径。

### SQL 示例

暂无。

## 16. CPM

别名：千次曝光成本、Cost Per Mille

定义：每千次广告曝光的成本；数学表达为花费 ÷ 曝光次数 ×1000。

计算公式：`CPM = 花费 / 曝光次数 * 1000`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 每千次曝光的成本，不能遗漏1000倍数。
- 公式依据名称含义整理；先核对第三方费用和曝光口径。

### SQL 示例

暂无。

## 17. IPM

别名：千次展示下载量、Installs Per Mille

定义：每千次广告展示带来的下载量；数学表达为下载量 ÷ 展示量 ×1000。下载量与安装量是否一致需确认。

计算公式：`IPM = 下载量 / 展示量 * 1000`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 白皮书定义为千次展示下载量；下载与安装是否相同须确认。
- 数学关系按定义整理，不得未经核对覆盖第三方平台直接返回值。

### SQL 示例

暂无。

## 18. CTR

别名：广告点击率、点曝比、Click-Through Rate

定义：广告点击次数 ÷ 广告曝光次数；目标页到达次数是否作为点击由广告来源口径确定。

计算公式：`CTR = 广告实际点击次数 / 广告曝光次数 * 100%`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 点击与曝光采用同一广告范围和窗口。
- 百分比显示只转换一次，不能平均各渠道CTR得到总体CTR。

### SQL 示例

暂无。

## 19. CVR

别名：点击安装转化率、Conversion Rate

定义：安装次数 ÷ 广告实际点击次数。

计算公式：`CVR = 安装次数 / 广告实际点击次数 * 100%`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 分子为安装次数，分母为实际广告点击次数。
- 归因窗口、安装去重及统计来源必须一致。

### SQL 示例

暂无。

## 20. CPI

别名：单位安装成本、Cost Per Install

定义：每次通过广告买量获得安装的成本；数学表达为买量花费 ÷ 对应买量安装量。

计算公式：`CPI = 对应买量花费 / 对应买量安装量`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 仅使用对应买量范围的安装量，不能混入自然量安装。
- 公式按单位成本定义整理，实际计算需核对第三方来源口径。

### SQL 示例

暂无。

## 21. CPA

别名：付费行为成本、单次付费成本、Cost Per Action

定义：**APX 中行为特指付费次数**。CPA＝花费 ÷ 付费次数；N 日 CPA＝花费 ÷ 注册起 N 日内累计付费次数，含注册当天。不得改为付费人数或注册人数。

计算公式：`N日CPA = 对应花费 / 注册前N日累计付费次数`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- APX中Action特指付费次数；不能替换为付费人数、注册人数或订单平均金额。
- N日付费窗口包含注册当天，花费与支付队列须有对应归因。

### SQL 示例

暂无。

## 22. ROI

别名：投放回报、投资回报率、Return on Investment

定义：APX 的 N 日 ROI＝对应注册队列 N 日内付费总额 ÷ 对应花费；原文另列 N 日 LTV ÷ CPI。支持分成前、分成后口径，不能改为利润减成本后的收益率。

计算公式：`N日ROI = 同一归因队列注册前N日累计付费总额 / 对应花费；对齐口径后可用N日LTV / CPI`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 必须说明分成前或分成后、币种、归因队列及累计收入窗口。
- 白皮书采用收入/花费，不能改为(收入-花费)/花费。
- 仅当获客人群、收入、费用及安装到注册映射一致时，N日LTV/CPI才与收入/花费等价。

### SQL 示例

暂无。

## 23. 付费设备数

别名：付费设备、N日付费设备数

定义：产生过付费的去重设备数。同一设备多个 UID 中任意一个付费即算付费设备；N 日指标以设备首次启动后的 N 日内观察，含首次启动当天。

计算公式：`N日付费设备数 = COUNT(DISTINCT 首次启动后前N日内有任意关联UID付费的设备)`

关联事件：当前工作空间配置的广告平台安装、曝光、点击、费用与归因数据；充值相关指标同时关联有效支付和设备账号映射

### 约束条件

- 同设备多个UID中任意UID付费即视为该设备付费。
- N日从设备首次启动起计算且包含当天，不能套用注册UID的生命周期起点。

### SQL 示例

暂无。

## 24. 留存率

别名：次留、次日留存、D1留存、D3留存、D7留存、Cohort Retention

定义：新增队列在注册后第 N 日登录的人数 ÷ 对应新增队列人数。1 日为次日，3 日、7 日分别为注册后第 3 日、第 7 日。24 小时留存另按注册后 24 至 48 小时登录人数 ÷ 注册满 48 小时的新增人数。

计算公式：`N日留存率 = 同一新增队列注册后第N日活跃人数 / 完整可观察的新增队列人数 * 100%`

关联事件：当前工作空间的新增或基期活跃队列及全部客户端行为日志；付费队列同时关联指定窗口的有效支付记录

### 约束条件

- N日为注册日加N个自然日的精确目标日；未成熟队列不进入成熟留存分母。
- APX按目标日任意客户端行为日志判定活跃，不能只筛选UserLogin或照抄参考文档的UserActive事件。
- 24小时留存单独观察注册后24至48小时，并以注册满48小时的新增用户为分母。

定义：统计日游戏在线时长 ≥1 小时的玩家，按日重新计算标签。

计算公式：`高活跃用户数 = COUNT(DISTINCT 统计日在线总时长>=1小时的UID)`

关联事件：当前工作空间的游戏在线时长记录，白皮书通常使用Logout打点

### 约束条件

- 单日在线时长≥1小时，按日更新。
- 与注册前3日累计>180分钟的新增核心SLG标签不同。

### SQL 示例

暂无。

## 72. 大R玩家

别名：大R人数、滚动30日大R

定义：统计日活跃且最近 30 天付费 ≥3000 美元的玩家，按日重新计算。原文同时引用 C5 以上付费档位；档位对应关系需数据源确认。

计算公式：`大R玩家数 = COUNT(DISTINCT 统计日活跃且最近30天累计付费>=3000美元的UID)`

关联事件：当前工作空间的客户端活跃行为与最近30天有效支付记录

### 约束条件

- 滚动最近30天累计充值≥3000美元且统计日活跃，按日更新。
- 不是注册前30日大R转化；不能以当前标签回填历史。
- 原文C5以上档位映射未完整给出，档位边界须确认。
- 有效支付、订单去重、退款、币种及金额单位由当前工作空间配置；美元阈值不得与其他币种直接比较。

## 73. 首次启动成功率

别名：首次登录成功率、首次启动成功率（会话）、首次启动成功率（设备）

定义：会话口径：首次启动且成功进入游戏的会话数 ÷ 首次启动会话数。设备口径：首次启动且成功进入游戏的设备数 ÷ 首次启动设备数。

计算公式：`会话口径 = 首次启动成功进入游戏会话数 / 首次启动会话数 * 100%；设备口径 = 首次启动成功进入游戏设备数 / 首次启动设备数 * 100%`

关联事件：当前工作空间定义的安装、重装、启动及成功进入游戏主界面事件

### 约束条件

- 首次安装后首次启动及卸载重装后首次启动都属于首次启动。
- 会话与设备口径须显式选择，分子分母使用相同单位。

### SQL 示例

暂无。

## 74. 非首次启动成功率

定义：会话口径：非首次启动且成功进入游戏的会话数 ÷ 非首次启动会话数。设备口径：非首次启动且成功进入游戏的设备数 ÷ 非首次启动设备数。

计算公式：`会话口径 = 非首次启动成功进入游戏会话数 / 非首次启动会话数 * 100%；设备口径 = 非首次启动成功进入游戏设备数 / 非首次启动设备数 * 100%`

关联事件：当前工作空间定义的安装、重装、启动及成功进入游戏主界面事件

### 约束条件

- 排除首次安装和卸载重装后的首次启动。
- 原文设备公式标题误写“首次”，其分子分母均为非首次；此处按公式主体归类。

## 75. 首次登录时长

别名：首次启动耗时

定义：首次启动时，从触发启动到成功进入主界面的耗时。白皮书提供平均数和中位数两种统计口径，输出必须标明采用哪一种。

计算公式：`首次登录时长 = AVG或MEDIAN(首次启动到成功进入主界面的耗时)`

关联事件：当前工作空间定义的安装、重装、启动及成功进入游戏主界面事件

### 约束条件

- 范围为启动到成功进入主界面，不是游戏在线时长。
- 输出必须标明平均数或中位数、耗时单位及失败样本处理；首次启动含卸载重装后首次。

暂无。

关联事件：当前工作空间定义的安装、重装、启动及成功进入游戏主界面事件

## 77. CCU

别名：同时在线人数、Concurrent Users

定义：某个时点同时在线的玩家数。不是当日累计活跃人数，也不能仅用登录事件人数代替。

计算公式：`CCU = COUNT(DISTINCT 指定时点处于在线状态的UID)`

关联事件：当前工作空间定义的在线状态或可还原在线区间的事件

### 约束条件

- 必须有指定时点的在线状态或可还原在线区间的数据。
- DAU和登录事件数不能直接替代同时在线人数。

### SQL 示例

暂无。

## 78. 支付成功率

别名：订单支付成功率

定义：完成支付的订单数 ÷ 调用支付接口的订单数。

计算公式：`支付成功率 = 完成支付的订单数 / 调用支付接口的订单数 * 100%`

关联事件：当前工作空间定义的支付接口调用、订单及最终支付状态记录

### 约束条件

- 统计订单数，不能使用接口调用条数、回调日志条数或付费人数代替。
- 明确重试去重、最终状态和观察窗口；未完成状态可能仍存在。

### SQL 示例

暂无。

## 79. 支付取消率

别名：订单取消率、玩家支付取消率

定义：玩家取消的订单数 ÷ 调用支付接口的订单数。

计算公式：`支付取消率 = 玩家取消的订单数 / 调用支付接口的订单数 * 100%`

关联事件：当前工作空间定义的支付接口调用、订单及最终支付状态记录

### 约束条件

- 分子为玩家取消的订单，分母为调用支付接口的订单。
- 订单去重和状态最终性须明确，不强制与成功及失败率合计100%。

## 80. 支付失败率

别名：订单支付失败率

定义：支付失败的订单数 ÷ 调用支付接口的订单数。

计算公式：`支付失败率 = 支付失败的订单数 / 调用支付接口的订单数 * 100%`

关联事件：当前工作空间定义的支付接口调用、订单及最终支付状态记录

### 约束条件

- 分子为失败订单，分母为调用支付接口的订单。
