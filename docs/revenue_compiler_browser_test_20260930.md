## 范围与限制

当前数据源的国家值在该用例中为 CN；NULL 分组另外由真实 PostgreSQL VALUES 测试验证，不宣称浏览器覆盖了未出现的 NULL 国家数据。

数据预览与本轮图表预览都已实际显示分组列，宽表需要横向滚动查看全部字段；不能只根据收入列绑定分支的静态代码断言渲染一定遗漏分组。超过十列和全 NULL 列的既有预览限制保留。按用户要求，本次不修改前端页面布局、控件或文案。
