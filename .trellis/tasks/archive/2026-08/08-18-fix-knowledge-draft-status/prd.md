# 修复知识库保存草稿状态不刷新

## Goal

保存草稿成功后编辑器仍显示旧的 READY_TO_PUBLISH 状态，需修复状态刷新并补充回归验证。

## Requirements

- 点击“保存草稿”成功后，编辑器展示的草稿状态必须与服务端最新版本一致。
- 普通文档继续使用知识块级保存和现有并发冲突检测；当没有产生知识块或结构保存请求时，保存动作仍必须提交当前草稿版本。
- 保存后的状态不得依赖前端猜测或硬编码，应以服务端返回或重新读取的版本数据为准。
- 不改变校验、发布、知识块冲突处理及其他知识类型的保存行为。

## Acceptance Criteria

- [x] `READY_TO_PUBLISH` 普通文档点击保存后，服务端草稿保存接口被调用，界面刷新为服务端返回的状态。
- [x] 有知识块或结构变更时仍通过原有细粒度接口保存，且不会额外覆盖并发修改。
- [x] 其他知识类型保存成功后同样重新同步服务端版本状态。
- [x] 前端聚焦回归测试及生产构建通过；完整布局测试和 ESLint 仍受基线问题影响，已记录。

## Notes

- 用户可见现象：保存草稿后仍显示 `READY_TO_PUBLISH`，按钮状态没有随版本状态变化。
- 本任务为单一前端状态同步 Bug，采用 PRD-only 轻量流程。
