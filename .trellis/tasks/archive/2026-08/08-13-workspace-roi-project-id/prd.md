# 工作空间绑定 ROI 项目 ID

## Goal

在 SaaS 后台的工作空间创建/编辑抽屉中，为工作空间配置可持久化的 ROI 项目 ID，供当前工作空间及管理端接口读取，建立工作空间与外部 ROI 项目的明确映射。

## Background

- 现有工作空间已经支持普通数据源、ROI 数据源和第三方 MCP 数据源绑定。
- ROI 数据源绑定存储在 `core_roi_workspace_config`；`sys_tenant` 当前没有 ROI 项目 ID 字段。
- `bound_project_id` 是普通数据源 ID 的历史兼容别名，不代表本需求中的外部 ROI 项目 ID，不能复用。
- ROI 数据源当前为可选项，已有工作空间允许未配置 ROI 数据源。

## Requirements

- 在“开通工作空间”和“编辑工作空间”的同一表单中，于“ROI数据源”下方增加“项目ID”输入框。
- 项目 ID 是 SaaS 管理端开通/编辑非默认工作空间时的必填属性，持久化在工作空间记录中，不写入用户数据源权限或普通数据源绑定。
- 项目 ID 使用文本格式：去除首尾空格后必须非空，最大长度 128 个字符；允许纯数字、前导零和字母混合值。
- 工作空间创建和编辑接口支持写入与更新项目 ID，并与该次工作空间修改保持同一事务；非默认工作空间不允许清空。
- 管理端工作空间列表/详情返回项目 ID；当前工作空间接口也返回项目 ID，供后续 ROI 功能获取。
- 默认工作空间沿用 ROI 配置限制：表单不要求且不可编辑该 ROI 相关属性，后端拒绝绕过前端直接为默认工作空间设置项目 ID。
- 变更进入工作空间操作审计，记录项目 ID 的设置值；默认工作空间记录为未修改。
- 不使用静默兼容兜底，也不把普通数据源 ID 当作 ROI 项目 ID 返回。
- 提供数据库迁移，列暂时保持可空以兼容历史工作空间；不自动推断或回填值，也不修改或删除已有绑定和历史数据。历史非默认工作空间下次编辑保存时必须补填项目 ID。
- 补充后端往返、校验、事务回滚测试和前端表单/API 契约测试；完成前端构建与实际页面验证。

## Acceptance Criteria

- [ ] 平台管理员创建非默认工作空间时必须在 ROI 数据源下输入项目 ID，保存后重新打开仍显示原值。
- [ ] 平台管理员编辑工作空间时可修改项目 ID；空值、纯空白或超过 128 个字符时前后端均拒绝保存。
- [ ] 管理端工作空间响应和 `/system/tenant/current` 均以独立字段返回项目 ID。
- [ ] 项目 ID 不会覆盖、推断或复用普通数据源绑定的 `bound_project_id`。
- [ ] 默认工作空间不能通过 UI 或 API 设置项目 ID。
- [ ] 迁移前已存在且项目 ID 为空的非默认工作空间仍可读取，但再次编辑保存时必须补填。
- [ ] 任一绑定或项目 ID 持久化失败时，本次工作空间修改整体回滚。
- [ ] 数据库迁移可升级和回退，已有工作空间保持可用且原数据不被清理。
- [ ] 相关后端测试、前端契约测试、前端构建和浏览器级创建/编辑回显验证通过。

## Out Of Scope

- 不修改 ROI 看板查询逻辑或把项目 ID 自动注入 SQL。
- 不新增按项目 ID 查询外部系统的接口。
- 不改变一个工作空间最多绑定一个普通数据源、一个 ROI 数据源的现有模型。
- 不对历史工作空间自动推断或回填项目 ID。
- 不扩展现有用户自助申请/审批模型采集项目 ID；由该历史流程创建的工作空间保持数据库空值兼容，并在 SaaS 管理端首次编辑时要求补填。

## Key Decisions

- 用户确认使用文本输入框并设为必填项。
- 必填规则属于 SaaS 管理端的非默认工作空间创建/编辑契约，不依赖是否同时选择 ROI 数据源；ROI 数据源仍保持现有可选行为。
- 为无损升级，数据库字段保持可空，但创建/编辑 API 对非默认工作空间执行必填校验。
