# Bug Analysis: 知识块删除后无反馈

## Root Cause

- 类别：D - 测试覆盖缺口。
- 删除确认后的本地草稿更新逻辑完整，但成功路径没有用户可见反馈。
- 原回归测试只验证知识块结构变化，没有验证删除操作的反馈语义。

## Fix

- 在本地草稿删除完成后显示“知识块已删除，请保存草稿”。
- 保持现有保存草稿落库、取消确认、单块保护和只读行为不变。
- 在已有编辑器布局测试中增加成功反馈断言。

## Verification

- 知识库聚焦测试 19 项通过。
- `DocumentEditor.vue` 定向 ESLint 通过。
- 前端生产构建通过。
- `git diff --check` 通过。

## Prevention

- 后续调整草稿型破坏操作时，同时验证状态变化和用户可见反馈。
- 本次问题局限于现有组件成功路径，未形成新的跨模块约定，因此不更新全局 spec。
