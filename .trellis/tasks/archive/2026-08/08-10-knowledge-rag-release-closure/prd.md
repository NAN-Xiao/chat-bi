# 完成知识库 RAG 发布前收尾验收

## Goal

在不改变既有 Skills 逻辑、不开启 MCP、不中断已完成迁移的前提下，完成知识库 RAG 发布前的真实链路、页面和运行门禁验收，并形成可合并到 `release/release_2.0.0` 的证据。

## Requirements

- 对“报告解读”场景完成一次真实鉴权调用，确认检索、权限过滤、提示词上下文和审计记录均使用 `surface=report_interpretation`。
- 对“综合分析助手”完成一次真实数据计算成功请求；失败时定位并修复通用链路问题，不通过硬编码业务口径或静默降级掩盖错误。
- 对知识库管理、结构化编辑、检索预览及权限相关页面在 `1366x768`、`1440x900`、`1920x1080` 下进行浏览器验收，检查统一样式、操作可见性和无横向溢出。
- 只读执行迁移 `status`/`verify`；不执行 `enter-barrier`、`activate-v2`、回退或删除数据命令。当前数据库已处于 `V2_ACTIVE`。
- 核对当前分支与主工作区用户改动，保留主工作区未提交内容；仅在分支证据完整后整理合并方案。
- 记录测试、联调、页面截图、迁移门禁和遗留风险；所有用户可见错误保持中文安全提示。

## Acceptance Criteria

- [ ] 报告解读真实调用成功或有明确的阻塞证据、修复记录和回归验证。
- [ ] 综合分析助手返回至少一项真实计算结果，且响应中包含检索审计关联信息或可追溯记录。
- [ ] 三个桌面视口页面均无页面级横向滚动，顶部操作区无隐藏溢出，主要按钮/抽屉/分页可用，截图已保存并检查。
- [ ] `knowledge_base_migrate.py status` 与 `verify --compatible-builds-confirmed` 的输出已记录；若因 Worker/存储探针缺失不能通过，文档明确列出阻塞项，不伪造就绪。
- [ ] 后端测试、前端构建和必要的定向检查通过；实际监听进程与环境参数已核对。
- [ ] Trellis 任务包含实现、检查和收尾记录；变更已提交到中文提交信息的功能分支并推送，未覆盖主工作区改动。
