# 质量检查记录（2026-08-12）

## 已修复问题

1. 结构保存曾信任客户端隐藏元数据、既有块内容和新块版本号。现改为以加锁后的服务端 payload 为准：隐藏元数据原样继承，既有块内容与版本由服务端持有，新块固定从 `block_revision=1` 开始。
2. 并发删除块后，页面文案声称保留本地内容，但原流程只能刷新并丢弃本地值。现增加“恢复为新知识块”，生成新稳定 ID，并基于最新服务端结构版本重试。
3. 编辑期移除知识类型切换后，创建流程无法创建非文档知识。现将知识类型改为创建时一次性选择，后端校验并持久化；编辑页仍禁止切换类型。
4. 块级保存和结构保存没有满足 AC9 的操作审计。现通过现有 `sys_logs` 写入租户隔离审计，记录文档、版本号、版本修订、操作人、操作类型和受影响块 ID，并与草稿写入使用同一事务。
5. 审计分类曾将 Markdown 规范化差异误判为正文修改。现按规范化后的 Markdown 比较实际变更。
