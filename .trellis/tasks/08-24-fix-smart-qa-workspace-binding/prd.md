# 修复 Smart Q&A 工作空间数据源绑定状态

## 需求

当用户进入已绑定数据源的工作空间并在 Smart Q&A 提问时，不应继续显示“当前工作空间未绑定数据，AI 看板暂不可用”。需要沿工作空间切换、可访问数据源接口、前端数据源上下文及会话创建链路定位并修复根因。

## 约束

- 数据源访问必须继续以当前工作空间绑定和权限为准，不增加跨工作空间兜底。
- 不通过硬编码数据源 ID、工作空间 ID 或静默选择其他数据源来掩盖问题。
- 保留无绑定工作空间的明确提示行为。

## 验收标准

1. 已绑定且有权限的数据源可被 Smart Q&A 会话创建链路使用。
2. 工作空间切换后数据源上下文不会因旧请求、缓存或状态竞态而被错误清空。
3. 未绑定数据源时仍显示明确的未绑定提示。
4. 增加覆盖根因的回归测试，并完成前端构建和相关后端测试。
