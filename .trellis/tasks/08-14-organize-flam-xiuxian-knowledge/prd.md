# 整理 flam 和修仙业务术语与 SQL 示例

## Goal

基于当前系统数据库中的 flam 与修仙 Data Skill，输出一份可供知识库录入和后续人工校验的 Markdown 整理文档，明确可抽取的业务术语、SQL 示例来源，以及必须继续保留在 Data Skill 中的执行约束。

## Requirements

- 只读查询当前星通数智系统数据库中的活动 Data Skill，不修改数据库记录。
- 覆盖 flam 数据源 ID 3 的 SQL-rich 工作空间 Skill：225、226、229、230、231、232、233、235、236、237、238、239、240、241、242、243。
- 覆盖修仙数据源 ID 6 的业务 SQL-rich 工作空间 Skill：257、269、270、271、272、273、274、275、276、277、278、279。
- 将修仙 Skill 255 作为日期和按日聚合执行契约单独说明，不将其整体建议为业务知识。
- 每个 Skill 至少记录来源 ID、名称、适用知识形式、SQL 代码块数量、建议拆分的术语方向和保留在 Skill 的内容。
- 汇总 SQL 代码块的方言解析、重复情况和进入知识库前仍需执行的校验门禁。
- 不复制用户私有 Skill，不包含数据库凭证、用户信息或未脱敏敏感配置。
- 明确知识库业务知识是参考内容，不能覆盖当前数据源、权限、Schema、事件/JSON 映射或 Data Skill 规则。
- 在整理报告之外，生成两份可上传的知识库 Markdown：flam 与修仙各一份。
- 可上传文档按业务问题保留代表性 SQL，不机械复制全部重复看板 SQL；每个 SQL 示例保留目标 MySQL 方言、参数占位符和来源 Skill。

## Acceptance Criteria

- [x] 仓库中生成一份中文 Markdown 文档，flam 与修仙候选 Skill 均有完整清单。
- [x] 文档区分“适合抽取为业务术语/SQL 示例”“混合内容需拆分”“必须保留在 Data Skill”。
- [x] 文档给出适配现有 BUSINESS payload 的字段映射和推荐录入粒度。
- [x] SQL 统计与当前数据库一致，并记录只读的解析/去重检查结果。
- [x] 文档不建议整体迁移 Data Skill，不改变任何运行时配置或数据库内容。
- [x] 生成 flam 与修仙两份独立知识库 Markdown，包含业务术语、计算口径、示例问题、代表性 SQL 和使用限制。
- [x] 两份 Markdown 不跨数据源复用物理表、产品标识或 SQL。

- 来源内容以 2026-08-14 查询到的活动 Data Skill 为准。
