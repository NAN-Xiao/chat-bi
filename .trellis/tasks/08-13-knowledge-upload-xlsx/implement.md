# 实施记录

## 数据流

1. 新建普通文档时可选源文件；系统先创建知识库与草稿，再调用 `/knowledge-base/{id}/draft/file` 上传。
2. 已有普通文档草稿可在编辑抽屉中替换源文件。
3. 后端校验扩展名和 50 MB 限制，解析 Markdown、Word 或 Excel。
4. Excel 以非空工作表为知识块边界，保留单元格文本与公式；空工作表跳过。
5. 解析结果替换草稿 blocks，后续沿用校验、发布、向量切片流程。

## 关键约束

- 上传只更新草稿，不覆盖已发布版本。
- `.xlsx` 使用只读工作簿模式，并检查压缩包解压总量和异常压缩比。
- V2 与旧版扩展名选择器保持一致。
