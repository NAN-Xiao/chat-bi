# 精简知识块内容编辑界面

## Goal

移除知识文档编辑器中的知识块结构管理功能，使右侧区域聚焦展示和编辑当前知识块的 Markdown 内容。

## Background

- 截图明确标出了顶部“新增知识块”按钮，以及当前知识块头部的启停、上移、下移、复制、删除操作。
- 当前实现位于 `frontend/src/views/knowledge-base/editors/DocumentEditor.vue`。
- 多知识块文档仍需要左侧目录来选择要查看的知识块，后端数据结构与保存协议不变。

## Requirements

- 移除“新增知识块”入口。
- 移除当前知识块的启停、上移、下移、复制和删除入口。
- 移除左侧目录中的标题编辑入口。
- 保留右侧知识块标题栏中的序号和标题，仅移除其中的块级管理操作。
- 右侧详情区保留当前知识块标题栏和 Markdown 内容区域。
- 保留左侧知识块目录及选中切换能力，避免多知识块文档只能看到第一块。
- 不改动已有知识块数据、排序、启停状态或后端接口。
- 桌面端和移动端均不得因工具栏移除出现横向溢出或无效留白。

## Acceptance Criteria

- [ ] 页面中不再出现“新增知识块”按钮。
- [ ] 页面中不再出现知识块启停、上移、下移、复制和删除操作。
- [ ] 页面中不再出现知识块标题编辑入口。
- [ ] 选择左侧任一知识块后，右侧显示该块的序号、标题和 Markdown 正文，不显示块级管理操作。
- [ ] 保存现有文档时，未编辑的知识块结构字段保持不变。
- [ ] 前端构建和聚焦布局测试通过，并完成桌面、移动端浏览器验证。

## Out Of Scope

- 删除多知识块数据模型或将多块内容合并为单块。
- 修改知识库级保存草稿、校验、发布流程。
- 修改后端 API、数据库或既有文档数据。

## Key Decision

- 用户确认删除左侧标题编辑入口，但保留右侧显示序号与标题的知识块标题栏。
