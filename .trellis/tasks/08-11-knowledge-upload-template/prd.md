# 增加知识库 Markdown 上传模板

## Goal

在知识库管理页提供四类 Markdown 上传模板下载，模板内容按现有标题切片规则组织。

## Requirements

- 在知识库管理页提供“下载 Markdown 模板”下拉入口。
- 提供普通文档、业务术语与 SQL、事件参数、表字段与 JSON Path 四类模板。
- 模板使用 UTF-8 Markdown，按现有标题切片规则组织，SQL 使用围栏代码块。
- 下载在浏览器本地完成，不新增后端接口，不改变上传、解析、发布和权限逻辑。
- 模板内容与下载逻辑放在独立 TypeScript 模块，避免继续扩大页面组件。
- 入口沿用 Element Plus 图标、按钮和下拉菜单样式，并兼容窄屏换行。

## Acceptance Criteria

- [x] 四类模板均可从知识库管理页真实点击下载，文件名和内容与选择项一致。
- [x] 模板包含填写提示和可替换示例，不包含真实凭据或固定数据源 ID。
- [x] 前端生产构建和 TypeScript 检查通过。
- [x] 桌面和当前支持的 768px 窄屏无页面级横向溢出，操作区文字和按钮不重叠；390px 下新增控件不再扩大内容区，剩余页面级溢出来自既有全局顶栏和固定侧栏。
- [x] 现有知识库创建、编辑、上传和发布入口保持可用。

## Notes

- 本任务只增加下载模板能力，不自动把 Markdown 标题解析为结构化对象引用。
- 发布前真实上传模板后，Smart Q&A 必须能处理同一知识版本命中的多个切片；知识版本哈希不得直接比较字典对象。
