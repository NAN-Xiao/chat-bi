# 知识库校验发布移除 datasource_id 依赖

## 需求

1. 知识库编辑器点击“校验”时，不再传递 `datasource_id`。
2. 后端知识库草稿校验请求模型不再声明 `datasource_id`。
3. 后端校验入口不再读取数据源目录、工作空间绑定、用户数据权限或 `physical_schema_hash`，也不因这些状态失败而阻断知识内容校验。
4. 校验与发布只依赖知识库草稿自身的版本、修订号、内容 hash 和内容结构校验。

## 范围

- 前端知识库校验请求 payload 与点击流程。
- 后端知识库草稿校验接口的请求模型和调用边界。
- 针对 datasource_id 不再传递/读取的回归测试。

## 非目标

- 不删除或放宽通用权限服务、数据源绑定服务或目录同步逻辑；其他数据源功能保持不变。
- 不改变知识文档自身的结构、SQL、字段和事件规则。

## 验收标准

- 前端校验请求体不包含 `datasource_id`。
- 后端请求模型和校验入口不包含 datasource_id 分支或 validation context 构建调用。
- 没有数据源上下文时，知识库草稿仍可按内容自身规则完成校验和发布前状态转换。
- 现有知识库 payload 校验和其他数据源功能测试保持通过。
