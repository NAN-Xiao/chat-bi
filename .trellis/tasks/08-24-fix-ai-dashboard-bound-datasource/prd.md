# 修复 AI 看板工作空间绑定数据源上下文

## Goal

AI 看板始终使用当前工作空间唯一绑定且有权限的数据源，消除未绑定误判。

## Requirements

- AI 看板与 Smart Q&A 必须使用当前工作空间唯一绑定且当前用户有权访问的数据源。
- 当前工作空间数据源接口成功返回唯一数据源时，前端应直接建立该数据源上下文，不依赖浏览器缓存或历史手工选择。
- 不得从其他工作空间、问题文本、首个任意数据源或 ROI 数据源推断普通 AI 看板数据源。
- 成功返回空列表时才显示当前工作空间未绑定数据源；接口失败必须保留为请求错误。
- 工作空间切换后旧空间的选中数据源不得进入新空间上下文。

## Acceptance Criteria

- [x] 已绑定一个可访问数据源的工作空间可以直接创建 AI 看板问答会话，不显示未绑定提示或数据源选择弹窗。
- [x] 浏览器没有该工作空间的数据源缓存时，仍使用接口返回的唯一绑定数据源。
- [x] 工作空间确实未绑定可访问数据源时，继续显示明确的未绑定提示。
- [x] 数据源接口失败时显示真实错误，不显示未绑定提示。
- [x] 多条异常结果不盲选任意数据源，现有显式选择流程保持可用。
- [x] 根因回归测试、工作空间切换测试和前端构建通过。

## Notes

- 后端 `/datasource/accessible/list` 已按当前请求中的工作空间绑定关系和权限过滤；前端消费该结果，不新增跨空间回退。
