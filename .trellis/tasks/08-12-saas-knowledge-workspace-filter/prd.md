# SaaS后台按工作空间筛选知识库

## Goal

让 SaaS 后台知识库管理明确区分平台知识库和工作空间知识库，并按平台管理员、工作空间管理员、普通成员三档角色提供正确的查看和编辑权限。

## Requirements

- 页面提供知识库范围下拉框，选项为“平台知识库”和“工作空间知识库”。
- 页面提供工作空间下拉框；选择“工作空间知识库”时用于确定目标工作空间。
- SaaS 平台管理员可以加载全部工作空间，并切换目标工作空间。
- 工作空间管理员和普通成员的工作空间下拉框固定为当前工作空间，不得选择其他工作空间。
- 选择具体工作空间时，知识库列表只返回该工作空间的知识库；选择平台知识库时，只返回平台公共知识。
- 平台管理员的工作空间筛选必须由后端按 `tenant_id` 授权和过滤，不能依赖前端全量拉取后隐藏。
- 知识库详情、创建和归档操作必须保留选定的工作空间上下文，避免列表筛选与操作目标不一致。
- 平台管理员可以创建、编辑、发布和归档平台知识库及任意选中工作空间的知识库。
- 工作空间管理员只能查看平台知识库，可以创建、编辑、发布和归档当前工作空间知识库。
- 普通成员可以查看平台知识库和当前工作空间知识库，但没有创建、编辑、发布、归档或工作空间启停权限。
- 普通工作空间用户不得通过新增参数访问其他工作空间。
- 同时支持知识库管理 V2 与 LEGACY 页面；能力探测失败时继续遵循显式错误状态，不静默降级。

## Acceptance Criteria

- [x] 所有角色进入知识库管理页后能看到范围下拉框；工作空间范围下显示工作空间下拉框。
- [x] SaaS 管理员切换两个工作空间时，列表请求带对应 `tenant_id`，页面只显示对应工作空间知识库。
- [x] 工作空间管理员和普通成员只能看到当前工作空间，不能切换到其他工作空间。
- [x] 平台知识库可单独查看，且只有 SaaS 管理员能编辑。
- [x] 工作空间管理员可以编辑当前工作空间知识库；普通成员只能查看两类知识库。
- [x] 后端拒绝非平台管理员使用其他工作空间的 `tenant_id` 查询或写入，并允许平台管理员管理目标工作空间知识库。
- [x] 前端生产构建和知识库相关后端测试通过。
- [x] 浏览器验证桌面与移动视口无页面横向溢出，真实切换流程可用。
