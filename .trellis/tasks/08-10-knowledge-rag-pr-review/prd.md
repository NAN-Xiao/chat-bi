# 知识库 RAG 发布审查与 PR

## Goal

完成知识库与 RAG 功能分支的发布前审查，并在确认无 P0/P1 阻塞后创建面向 `release/release_2.0.0` 的中文 PR。

## Background

- 功能实现、迁移、真实链路验证、前后端质量检查和分支推送已经完成。
- 功能 worktree 为 `D:/AIWork3/chat-bi-ver-worktrees/knowledge-base-rag`，分支为 `codex/knowledge-base-rag`。
- 主工作区包含用户未提交内容，必须保持原样，不得合并、覆盖、重置或暂存。
- 应用数据库已处于 `V2_ACTIVE`，本任务不得再次执行切换、回填或回退。

## Requirements

- 审查目标分支与功能分支之间的全部提交和文件差异，按 P0-P3 记录确认问题与残余风险。
- 重点核对权限边界、工作空间与数据源隔离、发布并发、对象解析继承、生命周期、审计及迁移兼容性。
- 比较功能分支变更文件与主工作区未提交文件，明确潜在重叠，但不修改主工作区。
- 若存在 P0/P1 问题，停止创建 PR并明确报告；若不存在，检查重复 PR 后创建中文 PR。
- PR 必须说明验证结果、数据库当前迁移状态、MCP 未纳入本次链路，以及主工作区未提交内容未包含在 PR 中。

## Out of Scope

- 新增或修改产品功能。
- 再次执行数据库迁移切换、回填、回退或数据清理。
- 修改、暂存、提交或合并主工作区的未提交内容。
- 启用或测试 MCP 链路。
