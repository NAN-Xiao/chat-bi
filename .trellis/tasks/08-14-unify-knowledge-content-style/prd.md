# 统一结构化知识内容样式

## Goal

将知识类型“业务术语与 SQL”“事件参数”“JSON 字段”的内容编辑区域统一为“普通文档”知识块的视觉样式，降低同一知识库页面内的样式割裂，同时保留三类知识现有的结构化编辑、校验和发布能力。

## Background

- 当前普通文档使用带标题区、边框和正文区的知识块容器。
- 业务术语与 SQL、事件参数、JSON 字段直接展示结构化表单，视觉层级与普通文档不同。
- 四类知识通过判别联合 payload 分别保存；事件参数、JSON 路径和业务 SQL 仍需保持结构化语义，不能改成仅保存 Markdown。

## Requirements

- R1：业务术语与 SQL、事件参数、JSON 字段三个编辑器使用与普通文档知识块一致的内容容器、标题区、边框、背景和正文间距。
- R2：三个编辑器继续展示并编辑各自现有字段，不删除、重命名或静默转换结构化字段。
- R3：保存、校验、发布、只读和版本历史流程保持现有行为，不修改前后端 payload 契约。
- R4：抽取共享的视觉容器，避免四个编辑器复制知识块结构和样式；普通文档也使用该共享容器，确保后续样式不会再次分叉。
- R5：桌面端与窄屏下内容不得产生页面级水平溢出、文本重叠或不可操作控件。
- R6：增加聚焦回归测试，证明四类编辑器都使用同一个文档式内容容器，且三类结构化编辑器仍保留原编辑入口。
- R7：普通文档编辑器在“知识块”标题区提供“新增知识块”操作；新增块追加到目录末尾、自动成为当前块，并使用可通过后端标题校验的默认标题。
- R8：普通文档当前知识块标题区提供“删除”操作；删除已有块前必须二次确认，确认后切换到相邻块，取消确认不改变草稿。
- R9：普通文档至少保留一个知识块；只剩一个块时禁止删除并给出明确提示，不自动创建替代块。
- R10：新增和删除只修改当前草稿，仍由现有“保存草稿”操作统一提交；只读、归档、无草稿或发布中的编辑器不展示可用的增删入口。

## Out Of Scope

- 不把 BUSINESS、EVENT、JSON_FIELD 数据迁移为 DOCUMENT 或 Markdown。
- 不修改知识类型选项、后端 Schema、数据库、发布与检索逻辑。
- 不重做结构化字段本身的交互方式或业务校验规则。
- 不调整知识库列表、顶部工具栏、生命周期按钮和版本历史布局。
- 不为 BUSINESS、EVENT、JSON_FIELD 引入多知识块数据结构；“新增/删除知识块”仅适用于已有 blocks 契约的普通文档。
- 不在本次恢复复制、排序、停用或标题编辑功能。

## Acceptance Criteria

- [ ] AC1：打开“业务术语与 SQL”知识时，内容区具有与普通文档一致的知识块标题区、边框和正文区样式，原业务术语、定义、公式、约束、关联对象和 SQL 示例仍可用。
- [ ] AC2：打开“事件参数”知识时，内容区具有相同文档式样式，事件基本信息和事件参数编辑仍可用。
- [ ] AC3：打开“JSON 字段”知识时，内容区具有相同文档式样式，Schema、物理表、路径、表达式、说明和值映射编辑仍可用。
- [ ] AC4：普通文档与三类结构化知识使用同一个共享视觉容器组件，不存在四份平行容器样式。
- [ ] AC5：前端聚焦测试和生产构建通过。
- [ ] AC6：实际知识库页面在代表性桌面与移动视口中无页面级水平溢出，截图人工检查通过。
- [ ] AC7：可从知识块标题区新增一个带非空默认标题的空白块；目录数量增加，新增块立即成为当前块，保存草稿后重新打开仍存在。
- [ ] AC8：可从当前知识块标题区删除该块；删除前显示确认框，确认后数量减少且选择相邻块，取消后数据不变。
- [ ] AC9：只剩一个知识块时不能删除；只读状态不显示新增和删除操作。
- [ ] AC10：结构版本冲突仍进入现有显式冲突处理，不覆盖服务端知识块结构。

## Technical Notes

- 现有普通文档视觉基线位于 `frontend/src/views/knowledge-base/editors/DocumentEditor.vue` 的 `knowledge-block`、`block-header` 和 `block-body`。
- 结构化编辑器位于 `frontend/src/views/knowledge-base/editors/BusinessKnowledgeEditor.vue`、`EventKnowledgeEditor.vue`、`JsonFieldKnowledgeEditor.vue`。
- 本任务为单层前端视觉统一，按轻量任务处理，仅维护 PRD；实现前仍需完成 Trellis 阶段批准。
- 新增/删除沿用 `KnowledgeBaseV2Panel.vue` 的结构差异检测与 `saveDocumentStructure` 保存路径，不增加新 API。
