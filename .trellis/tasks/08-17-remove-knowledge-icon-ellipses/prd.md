# 移除知识块操作图标椭圆外框

## Goal

移除知识库普通文档编辑器中“新增知识块”和“删除知识块”图标外围的椭圆按钮视觉，让操作区更简洁，同时保留完整交互能力。

## Requirements

- 新增与删除操作保留原有 `Plus` / `Delete` 图标、tooltip 和可访问性标签。
- 去掉两个操作的椭圆边框、背景和 Element Plus 默认按钮外观，保留稳定的图标点击区与明确的 hover/focus 反馈。
- 不改变只读态的显隐逻辑、新增知识块逻辑、删除确认逻辑及至少保留一个知识块的限制。
- 修改仅限于知识库普通文档编辑器及其聚焦布局测试。

## Acceptance Criteria

- [x] 桌面端和移动端中，新增与删除图标外部不再显示椭圆边框或白色按钮底。
- [x] 两个图标仍可点击，tooltip 与键盘 focus 状态正常，只读态下仍隐藏。
- [x] 新增知识块、删除确认及最后一个知识块保护行为保持不变。
- [x] 聚焦布局测试和前端生产构建通过，实际页面截图确认无水平溢出或操作区重叠。

## Out Of Scope

- 不调整图标含义、位置、知识块数据结构或后端 API。
- 不将本次视觉变更扩展到其他 Element Plus 图标按钮。

## Confirmed Decisions

- 用户在 2026-08-17 确认继续实现上述轻量方案。
- 本任务为 PRD-only 轻量调整，无需独立 `design.md` 或 `implement.md`。
